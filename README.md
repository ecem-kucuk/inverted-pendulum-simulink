
# Inverted Pendulum on a Cart
### Nonlinear Dynamic Modelling using MATLAB/Simulink

## Overview
This project focuses on the mathematical modelling and simulation of an inverted pendulum mounted on a moving cart.

The objective is to investigate the nonlinear dynamics of the system and observe its response to different inputs and initial conditions.

## Technologies Used
- MATLAB
- Simulink
- Control Systems
- Mathematical Modelling
- Nonlinear System Analysis

## System Description
The system consists of a cart and an inverted pendulum.

The model uses four state variables:
- Cart position (x)
- Cart velocity (dx/dt)
- Pendulum angle (theta)
- Pendulum angular velocity (dtheta/dt)

The input is an external force applied to the cart.

## Model Implementation
The nonlinear equations of motion are represented using mathematical operation blocks and integrators in Simulink.

The model is designed to observe:
- Cart displacement
- Pendulum angular position
- Cart velocity
